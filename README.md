# What is [Project Butterfly]?
**[Project Butterfly]** is an immersive cinematic video game, currently in production by a group of MUIC (Mahidol University International College), Creative Technology major students.
The project was started to showcase the technical and artistic skills of MUIC Creative Technology students, ranging from programming and 3D modeling pipeline to music composition and computer animation. These skills were honed throughout the years at MUIC, utilizing many digital software as aids and tools, ultimately hoping to reach working-grade professionalism in creative and technological production(s).

## Game Overview
[Project Butterfly] is a 3D single-player/couch-multiplayer video game, set in a futuristic and sci-fi setting where the player makes decisions at crucial moments to slowly unveil the secrets and the deep narrative given. This narrative is constructed with multiple pathways. Every decision matters, and every decision leads the player down a certain path whether they like it or not.

This project was started in the beginning of September 2024. The game itself is currently in production and have no plans to be released any time soon. The game is made, prioritizing console players and controller users (PS4/PS5) and may add Desktop/PC version into production in the future if the project's progress is stable and has a bright future.
